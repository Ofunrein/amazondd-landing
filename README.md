# Amazon Designs & Decor

A modern, responsive landing page for Amazon Designs & Decor, an event planning and decor rental business.

## Features

- Responsive design for all devices
- Interactive rental catalog with filtering
- Portfolio showcase
- Testimonials carousel
- Contact form
- Live chat feature

## Technologies Used

- HTML5
- CSS3 with Tailwind CSS
- JavaScript
- Font Awesome icons
- AOS (Animate On Scroll) library
